# Senior Pharmacist Portfolio

**A delivered professional website that turns a long healthcare career into a clear, responsive, shareable professional presence.**

[Live website](https://pharmacist-portfolio.vercel.app) · [Portfolio case study](https://omar-khair-portfolio.vercel.app/work/pharmacist-portfolio)

## Project

This client project was built to present a senior pharmacist's professional history, experience, qualifications, and contact information in a polished web format that is easier to share than a document-only CV.

The work focused on information hierarchy, career presentation, responsive layout, direct contact paths, and a professional visual system appropriate for a long healthcare career.

## What it proves

- **Client delivery** — translating real professional information into a finished public website.
- **Information architecture** — turning a long career history into readable sections and priorities.
- **Responsive implementation** — a usable experience across desktop and mobile.
- **Professional presentation** — direct contact, career proof, and CV-oriented content without unnecessary product complexity.
